A simple and responsive **Quiz Application** built using **React.js** and **Vite**. This project allows users to answer multiple-choice questions, receive instant feedback, track their score, and restart the quiz. It was built to practice **React Hooks, state management, event handling, conditional rendering, and responsive UI design**.

## ✨ Features

- 📝 Multiple-choice quiz questions
- ✅ Instant answer validation
- 🎯 Highlights correct and incorrect answers
- 📊 Live score calculation
- 📍 Question progress indicator
- 🔒 Prevents multiple answers for the same question
- 🔄 Reset quiz functionality
- 📱 Fully responsive design
- ⚡ Fast performance with Vite

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/RohitSutar1823/Quiz-App.git
```

### Navigate to the project

```bash
cd Quiz-App
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will run at:

```text
http://localhost:5173
```
